全新安装

  1. 下载安装包 点上方「下载安装包」，得到 Workbench_0.1.0_x64-setup.exe。
  2. 放行 Windows 提示 因未做代码签名，SmartScreen 可能拦截：点「更多信息」→「仍要运行」。
  3. 完成安装并启动 安装完成后从开始菜单启动「工作台」。
  4. 首次使用建议 到「设置」调刷新间隔与预算；到「AI 会话」点「扫描成本」汇总历史用量。

常见问题

安装与使用中最常被问到的几点。

Windows 提示「已保护你的电脑」或「未知发布者」，怎么办？

安装包未做代码签名（签名证书需付费），Windows SmartScreen 因此会有提示。 点「更多信息」→「仍要运行」即可。你也可以选择从源码自行构建，或直接下载免安装 exe。校验完整性可用 Release 页面提供的 SHA-256。

会不会把我的数据上传到云端？

不会。所有数据（项目、任务、成本账本、日志）都写在本机的 app data 目录。 应用只在你本机发起两件事：读 netstat 看端口，读本机 session 文件算成本。唯一的可选外连是探测本地的 opencode 服务（默认 4096 端口）， 失败也只是显示「未检测到」，不影响其它功能。

「成本计量」是怎么算出来的？准不准？

解析本机 Claude Code / Codex 会话 JSONL 文件中的 usage 字段，按内置的 40+ 模型价格计算。分三级可信度：measured（文件里有真实 usage 上报）、estimated（无 usage，按字符数启发式估算，可在设置里关掉）、 zero_pricing（型号无法识别，标为不计费而不乱编单价）。 Anthropic 的缓存 token 按官方语义单独计价（读 0.1×、写 1.25×）。

杀进程会不会误杀系统关键进程？

不会。PID 0/4 与 csrss、lsass、services 等关键系统进程被后端直接拒绝， 前端也有二次确认。此外终止前会刷新并校验进程身份，避免 PID 复用导致误杀。

关闭窗口后程序去哪了？怎么真正退出？

点关闭是隐藏到系统托盘（这是有意设计，便于常驻监控）。要真正结束进程， 右键托盘图标选「退出工作台」。快捷键 Ctrl+Shift+W 可随时显示 / 隐藏窗口。

支持 macOS / Linux 吗？

尚未验证。当前只在 Windows 上开发、测试与打包：端口采集写死 netstat -ano，安装包只产出 NSIS。代码里有 POSIX 分支但没有实际跑过， 因此不在 README 里声称支持。
